# 내보내기 · Markdown 정리 계획

설계 전체는 [PLAN.md](PLAN.md). 이 문서는 PLAN §8 뒤에 이어지는 추가 기능 두 가지를 다룬다.

## A. Markdown 정리 (먼저 진행)

**문제.** Claude 화면에서 복사한 글을 붙여넣으면 줄바꿈이 빠져 `…확인했습니다.2. 새 아이콘…`처럼 목록이 한 덩어리로 붙는다.
개행이 이미 없는 글이라 렌더링으로는 고칠 수 없고, 글 자체를 고쳐야 한다.

**방식.** 서식 도구줄에 **"Markdown 정리"** 버튼 하나. 누를 때만 동작한다(붙여넣을 때 자동으로 바꾸지 않는다 — 추측이 틀려도 사용자가 되돌릴 수 있어야 한다).
선택 영역이 있으면 그 부분만, 없으면 메모 전체에 적용한다. `MdFormat.tidy`(값 → 값)로 두어 위젯 없이 테스트한다.

규칙:
1. 문장 끝(`.` `!` `?` `:` `)`) 바로 뒤에 붙은 `N. ` 목록 번호 앞에 줄바꿈. 번호가 `1`이거나 직전 번호 + 1일 때만 (`v1.2. ` 같은 오탐 방지).
2. 목록 시작·제목(`#`) 앞뒤에 빈 줄, 연속 빈 줄은 하나로, 줄 끝 공백 제거.
3. 목록 기호 `*` `+` → `-`.
4. ``` 코드 블록 안은 건드리지 않는다.

하지 않는 것: 표 열 맞춤, 문장 중간의 글머리표(`- `) 복원 (오탐이 많다).
붙여넣기 단계에서 개행이 사라지는지 앱 쪽 원인은 별도로 확인한다 (메모장에 붙여넣어 비교).

## B. 내보내기 (데스크톱 전용, 이후)

모바일은 이미 공유 시트가 있으므로 **Windows·macOS·Linux에서만** "내보내기…"를 보인다. 저장 위치는 저장 창(`file_selector`)으로 받는다.

| 단계 | 형식 | 비고 |
|---|---|---|
| 1 | Markdown(.md), 이미지가 있으면 zip(`assets/` 포함) | 본문의 `../assets/` 경로 유지 |
| 1 | HTML(.html) | 이미지는 base64로 넣어 파일 1개 |
| 1 | 일반 텍스트(.txt) | 기존 "텍스트만"과 같은 변환 재사용 |
| 2 | PDF | 시스템 한글 폰트 임베딩 검증 필요 |
| 2 | 전체 백업 zip | 보드 메뉴, 휴지통 메모는 제외 |

제외: DOCX(비용 대비 효용이 낮다), 이미지 카드(PNG), JSON.
